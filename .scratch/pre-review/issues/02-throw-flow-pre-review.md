# 02: 扔瓶流程接入预审

**What to build:** 让扔漂流瓶走通预审主路径：当自动审核实际不可用且扔瓶者不是管理员时，扔瓶内容不再直接入海，而是作为待审投稿进入待审区（媒体文件在提交时即下载到本地媒体目录）；作者收到不含瓶子 ID 的待审回执，回执下附撤回按钮（复用现有引导按钮机制）和「预审结果出来后是否私信推送给自己」的选择（默认不推送，偏好随待审记录保存）；待审产生时通过现有主动私信通道向管理员推送含待审编号与内容摘要的通知。审核可用时或管理员扔瓶时，行为与现状完全一致。批量上传云漂流瓶验证不含待审区内容。

**Blocked by:** 01（待审区注册表模块与预审触发判定）

**Status:** ready-for-agent

- [ ] 审核不可用时普通用户扔瓶：投稿进入待审区、不入瓶子库、不占瓶子 ID、捞不到、不计入海里统计
- [ ] 作者回执不含瓶子 ID；回执下有撤回按钮和结果推送订阅选择；选择默认不推送且被持久保存
- [ ] 待审产生时管理员收到主动私信（含待审编号与摘要）；adminQQ 未配置时有告警日志且不崩溃
- [ ] 管理员扔瓶跳过预审直接入海；审核可用时全部用户行为与现状一致
- [ ] 批量上传云漂流瓶不包含待审投稿
- [ ] 新增回执/通知文案与按钮值走现有消息构造模块并有测试
