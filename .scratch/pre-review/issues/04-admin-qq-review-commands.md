# 04: 管理员 QQ 预审指令

**What to build:** 管理员在 QQ 端完成预审闭环：新指令「漂流瓶/通过投稿 <待审编号>」把待审投稿转正为瓶子——此时才分配瓶子 ID、入海、记录现有发布日志；新指令「漂流瓶/驳回投稿 <待审编号>」固定进入一轮理由输入 prompt（提供"跳过理由"按钮，理由可留空），确认后丢弃投稿与媒体文件。通过/驳回均写作者个人日志（新增日志类型）；订阅了结果推送的作者收到私信（含驳回理由，若有）；理由不公开。处理不存在的投稿时给出明确提示。指令命名用「投稿」，与术语表一致。

**Blocked by:** 02（扔瓶流程接入预审）

**Status:** ready-for-agent

- [ ] 通过后瓶子获得新 ID 并可被捞到；瓶子 ID 在此之前未被占用；作者日志记录发布事件
- [ ] 驳回指令固定进入理由 prompt；发送"跳过"或点跳过按钮可留空理由；驳回后投稿与媒体被删除
- [ ] 驳回理由仅出现在作者日志与订阅推送中，不出现在任何公开消息里
- [ ] 订阅了结果推送的作者在通过/驳回时收到私信；未订阅的作者只有日志
- [ ] 非管理员使用两条指令被拒绝；处理不存在的投稿有明确提示
- [ ] 操作后控制台面板待审列表同步刷新
