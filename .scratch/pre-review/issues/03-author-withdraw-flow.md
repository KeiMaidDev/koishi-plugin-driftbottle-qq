# 03: 作者撤回流程

**What to build:** 作者可以撤回自己的待审投稿：新指令「漂流瓶/撤回投稿」不带参数时列出本人名下的待审投稿（待审编号 + 内容摘要），交互对齐现有「删留言」的 prompt 选号流程；确认后投稿记录与已下载的媒体文件被彻底丢弃，效果与驳回一致。已被管理员处理（通过/驳回）的投稿提示无法撤回；投稿处理结果经由面板广播同步刷新，QQ 端与控制台面板状态一致。

**Blocked by:** 02（扔瓶流程接入预审）

**Status:** ready-for-agent

- [ ] 作者发送撤回指令后看到本人待审投稿列表（含待审编号与摘要）；没有待审投稿时有友好提示
- [ ] 选择编号撤回成功后：投稿离开待审区、媒体文件被删除；作者收到确认
- [ ] 撤回已通过或已驳回的投稿时提示"已处理，无法撤回"
- [ ] 其他用户的待审投稿不在列表中，也无法被撤回
- [ ] 撤回后控制台面板待审列表同步刷新
- [ ] 待审回执上的撤回按钮能引导作者进入本流程
