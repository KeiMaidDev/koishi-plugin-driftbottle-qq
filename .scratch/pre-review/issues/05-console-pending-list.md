# 05: 控制台面板待审列表

**What to build:** 控制台管理面板新增待审区区块：展示全部待审投稿（内容摘要、作者、类型）与待审数量；每份投稿附「通过 / 驳回」按钮，驳回按钮弹出可留空的理由输入框。面板操作与 QQ 端指令走同一套预审语义（通过转正入海、驳回丢弃投稿与媒体、写作者日志、触发结果推送）；操作后复用现有面板变更广播，QQ 端与面板双向刷新。面板权限维持现状（控制台登录本身）。

**Blocked by:** 01（待审区注册表模块与预审触发判定）、02（扔瓶流程接入预审）

**Status:** ready-for-agent

- [ ] 面板显示待审投稿列表与待审数量；投稿被处理后列表与数量即时更新
- [ ] 通过按钮使投稿转正入海（分配瓶子 ID），效果与 QQ 指令一致
- [ ] 驳回按钮弹出可留空的理由输入框；留空与填写理由的行为与 QQ 端一致
- [ ] 面板操作写作者日志、触发结果推送（订阅者收到）
- [ ] QQ 端指令处理投稿后面板同步刷新；面板操作后 QQ 端状态同步
- [ ] 面板服务层的待审逻辑有依赖注入式测试（模式对齐现有面板服务测试）
