# 06: WebSocket 实时刷新

**What to build:** 管理员不必手动刷新页面：新举报到达时面板实时亮起（统计条与列表更新）；任何管理员执行封禁/解封/删留言/忽略举报后，所有打开的面板即时反映变化。服务端在举报闭环事件与数据变更时通过控制台 WebSocket 广播，前端收到后重新拉取列表与统计。
