# AGENTS.md

## Agent skills

### Issue tracker

Issues 以 markdown 文件形式存放在 `.scratch/<feature-slug>/`（每特性一个目录，spec.md + issues/NN-slug.md）。See `docs/agents/issue-tracker.md`.

### Triage labels

使用五个默认规范角色作为标签：needs-triage、needs-info、ready-for-agent、ready-for-human、wontfix。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context（根 CONTEXT.md 术语表 + docs/adr/ 决策记录）。See `docs/agents/domain.md`.
